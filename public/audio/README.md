# Ambient audio for The Daily Practice

Drop royalty-free MP3s here to give the breathing sessions a background loop.
The app references these exact filenames; until they exist, that sound option
simply plays silence. (The soft in/out breath tones are synthesised live with
the Web Audio API, so sessions always work — with or without these files.)

- `bowls.mp3` — singing bowls
- `flute.mp3` — flute / ambient
- `ocean.mp3` — ocean waves

Only use audio you're allowed to use commercially (e.g. Pixabay, and note its
license). A seamless 1–3 minute loop, reasonably compressed, is plenty.
